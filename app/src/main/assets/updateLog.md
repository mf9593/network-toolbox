# 网络工具箱

## 版本 2.1.0
**更新时间：2026年10月23日**

- 重构主界面：底部导航、页面背景与系统栏适配
- 主界面移除顶部标题栏，内容区直接展示
- 调整底部导航高度与图标/文字间距，避免重叠
- 当前网络卡片支持 WiFi 标准换行显示，避免“Wi-Fi 6”被截断
- WiFi 页支持点击网络输入密码，通过系统 WiFi API 连接（Android 10+ 弹出系统确认）
- WiFi 频段/标准筛选改为图标点击下拉菜单，减少首屏筛选占用
- 扫一扫入口移动到 WiFi 页顶部，重做为全屏扫码界面
- 扫一扫支持动态扫描框、手电筒、相册图片识别、扫描历史
- 设置页移除扫一扫入口，避免重复
- 设备扫描支持有线网络，有线优先；即使移动数据是系统活动网络，也会读取以太网网段
- 有线网络的网关、DNS、本机 IPv4 改为读取系统 LinkProperties，比 /proc/net/route 更准确
- 设备扫描无网络时不再弹 Toast，改为在局域网页面中央显示提示和“打开网络设置”
- 移除设置中的日志查看功能，仅保留软件崩溃日志自动记录
- 停止记录网络状态、调试和广播日志，降低运行开销
- 所有二级页面标题栏去掉主题色背景，改为跟随系统浅色/深色的无背景样式
- 修复二级页面状态栏颜色与页面底色不一致的问题
- 二级页面标题、返回按钮、状态栏图标统一跟随系统明暗模式
- 权限管理页重构：图标卡片、授权状态标签、操作按钮与首页风格统一
- 全局卡片统一为 16dp 圆角、0dp 阴影，平板/大屏使用更大边距
- 底部导航标签调整为：首页 / 设备 / 无线 / 工具 / 设置
- 底部导航首页使用 home 图标，WiFi 图标更换为圆角线性 WiFi 图标
- 设备页空状态改用路由器矢量图标，修复图标不可见问题
- 无线页扫一扫入口改用自绘扫码框矢量图标
- 重构网络概览：当前网络 Hero 卡片、网关/DNS/频率/速率指标、信号曲线、网络详情与复制
- 工具箱改版：分组展示、搜索、最近使用、长按收藏
- 局域网设备：扫描/停止、扫描进度、IPv4/IPv6 与协议组合筛选、设备详情、端口扫描联动
- WiFi：真实发起扫描、Android 13+ 附近 WiFi 权限、当前连接卡片、频段/标准组合筛选、详情与密码复制
- 设置：重新分区，新增深色模式（跟随系统/浅色/深色）
- 修复：SSID 空指针、设备筛选逻辑、主题切换刷新、列表底部裁切、RecyclerView 高度
- 主题配色页改为卡片网格，新增当前主题色预览和色值显示
- 随机主题每次点击生成新的高辨识度颜色，预览、按钮和选中态立即同步
- 随机刷新按钮的背景色、文字色、图标色跟随主题色变化，并增加操作提示
- 无线页 WiFi 关闭状态改用 WiFi 关闭图标，空状态图标按权限/关闭/筛选状态切换
- 无线页频段/标准筛选改为带文字标签的筛选/调节图标，当前筛选状态用主题色高亮
- ONVIF 调试移除虚拟摄像头标签和服务，仅保留设备发现与 RTSP 预览
- 修复 ONVIF 命令调试结果列表未初始化导致的崩溃、命令索引错位和重启结果误判
- 修复 ONVIF WS-Security 重试时 SOAP Body 缺失、深色模式下结果文字不可读等问题
- 补齐 ONVIF GetCapabilities、GetServices、编码参数范围命令，媒体服务地址优先从设备能力读取
- ONVIF 重启增加二次确认和“免登录尝试重启”；标准 ONVIF 仍要求认证，匿名请求仅在设备允许匿名访问时有效
- 修复 RTSP 地址补认证时固定使用 admin 用户名的问题，并按 Profile 选择主/子码流
- Ping 页面重排为参数卡片 + 快速选择 + 历史记录 + 结果卡片，按钮和结果文字在深色主题下可读
- 全局填充按钮统一同步主题背景、文字和图标对比色，修复深色按钮文字发黑
- 设备详情增加 Ping 测试和端口扫描入口，点击后自动填入设备 IP 并直接开始扫描
- 工具箱优化搜索与收藏星标，避免同一工具重复出现
- SADP 扫描改用临时 UDP 端口发送探测并接收单播响应，兼容性更好
- SADP 增加 Basic/Digest 认证回退、凭据校验，修复 RTSP 预览跳转、视频码流选择和重启/校时结果误报
- WiFi 导入、导出、数据库、已保存网络页面统一 16dp 卡片、页面边距、按钮对比色和搜索栏样式
- 局域网聊天服务启动移到后台，避免端口协商阻塞界面；统一 Tab、好友卡片、设置卡片和发送按钮样式
- 内置浏览器首页增加标题说明、统一书签图标主题色、调整顶部/底部栏分隔线和首页间距
- 修复工具箱点击工具后返回时工具从分类中消失的问题，取消重复的最近使用/收藏快捷区，收藏改用卡片星标
- 修复图标转换预览会删除子分组 transform、描边图标被默认黑色填充、导出 XML 使用无效 root transform 的问题
- 设备扫描从 ARP/NDP 表保留设备 MAC，设备列表和详情显示 MAC，并支持跳转 MAC 厂商查询
- 无线详情增加 BSSID 厂商查询，点击 BSSID 或厂商查询自动跳转并填充查询
- 首页概览快捷工具新增 MAC 查询入口
- HTTP 调试修复结果标题/结果内容绑定错误，复制结果改为按钮，按钮和卡片统一无阴影样式
- 网页调试修复标题栏返回箭头颜色，增加复制结果按钮状态和 XPath 字符串表达式回退
- 全局 Material 按钮统一移除阴影和状态动画，工具页面按钮改为扁平化
- WiFi 导入支持 ZIP 解包、vivo 设置备份、旧版加密 title/content 导出、文本化 wifiConfig 数据库和开放网络
- 修复 MIUI ZIP64 备份导入失败：改用 ZipFile 读取，兼容扩展大小头
- MIUI 备份中的 NONE/OWE 开放网络按“空密码”导入，不再被跳过
- WiFi 导入改为应用内文件浏览器，可直接浏览 Download 目录，支持 JSON/XML/BAK/ZIP 等文件，不再依赖系统文件选择器
- 修复旧版加密备份中重复 JSON 对象键导致整份文件解析失败的问题，改为逐条提取 title/content 记录
- 横屏适配：增加横屏尺寸资源、工具网格 3/4 列、降低底部导航高度、RTSP 页面解除竖屏锁定、浏览器首页可滚动
- 网页调试使用说明移除表情图标，改为标题栏帮助按钮弹窗；结果卡片解析后显示
- 内置浏览器地址栏改为圆角样式，首页增加标题说明，顶部/底部工具栏分隔线统一
- 局域网聊天修复监听器重复注册，工具栏/卡片/发送按钮横竖屏样式统一
- 修复 WiFi 连接权限判断：Android 13+ 同时检查“附近设备”和“位置信息”，连接前提示缺失项
- 权限管理新增“附近 WiFi 设备”，并增加系统定位开关检查与开启引导
- WiFi 连接失败时显示具体权限/定位原因，便于排查
- 设备扫描进度条颜色跟随主题色
- 无线列表长按详情改为直接展示全部已保存密码，支持逐条复制和全部复制
- WiFi 文件选择器增加“根目录 / Download”快速路径，并记住上次目录
- 导出 WiFi 数据改为底部格式选择，列表间距压缩，全选按钮移到标题栏
- 导出列表显示多密码数量标签，修复 WiFi 图标不显示；数据库标签统一使用主题色
- 导出列表布局与数据库列表统一，多密码标签固定在密码行右侧
- 数据库搜索框加高美化；“清除空密码”支持清除“空密码”占位并显示在标题栏
- 设置增加“检查更新”，关于页补充开源仓库、协议、隐私与组件说明
- 项目补充 README、Apache-2.0 开源协议、隐私说明、第三方组件清单和 GitHub 忽略规则
- 数据库查询长按/点击统一为底部密码操作面板，支持复制、删除和撤销
- 网页调试帮助改为可滚动底部说明，完整保留换行和示例规则
- 设置页深色模式与主题配色使用独立的月亮/调色盘图标
- 设备扫描改为按本机 WiFi/以太网 IPv4 推导 /24 网段，补充 IPv6 全节点探测、全部 NDP 邻居和常见服务端口识别
- RTSP 播放器由 NodeMediaClient 替换为 Media3 ExoPlayer RTSP，移除商业授权依赖
- 版本号升级至 2.1.0（210）

## 版本 2.0.1
**更新时间：2026年7月8日**

- 调色板：修复SV面板触摸无效、渲染全白、填色按钮重复、改色偏色问题
- 局域网扫描：移除IP过滤限制，记录所有收到的设备响应
- 优先级重构：ONVIF/SSDP/路由器 > mDNS/NetBIOS/SADP/ARP/UDP > HTTP/Ping
- 新增ONVIF IPv6多播发现（ff02::c:3702）
- 新增广播日志：独立开关控制，记录所有协议原始响应数据
- 新增运行日志第三页"广播日志"标签
- 路由器后台扫描恢复内网IP过滤
- 修复QUIET模式IPv6邻居扫描被跳过
- 修复443端口HTTPS标题获取（支持自签证书）
- Ping停止误报（InterruptedIOException）不再写入错误日志
- 聊天室组播端口从5001改为19105，避免冲突
- 聊天室组播监听静默忽略非JSON数据
- SADP自动解析型号和序列号作为设备标题
- 设备列表默认隐藏IPv6，可通过筛选查看
- 图标替换：浏览器、DNS反查、已保存网络、设备信息
