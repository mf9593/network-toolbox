# 使用帮助

网络工具箱是一款面向 Android 的网络调试与诊断工具，无需 Root 即可完成大部分网络分析工作。以下按页面功能逐一介绍。

## 信息页面

当前网络连接状态总览：

- 显示 WiFi 连接状态、信号强度、IP 地址、网关、DNS
- 展示设备硬件信息与网络接口详情
- 点击网关 IP 可直接跳转路由器管理页面

## 设备页面

局域网设备发现与扫描：

- 自动发现路由器网关和局域网活跃设备
- 支持多协议（ARP、mDNS、SSDP、ONVIF、SADP、NetBIOS、UDP 广播）混合扫描
- 显示设备 IP、MAC 地址、厂商及开放服务
- 点击设备可查看详情或打开管理页面
- 支持自定义扫描 IP 段和协议组合

## 无线页面

WiFi 相关工具集中管理：

- 查看当前连接的 WiFi 详细信息
- 导入/导出保存的 WiFi 网络配置
- 数据库管理：搜索、复制密码、删除记录
- 系统已保存网络列表查看

## 工具页面

提供多种网络调试工具，分为以下类别：

### 网络诊断
- **Ping**：测试网络连通性与延迟，支持自定义参数、历史记录
- **端口扫描**：扫描指定 IP 的开放端口
- **IP扫描**：扫描局域网活跃设备
- **MAC地址查询**：查询 MAC 地址所属厂商
- **DNS优选**：域名解析记录查询
- **路由跟踪**：追踪数据包到目标的路径节点
- **域名查询**：Whois 域名信息查询
- **DNS反查**：IP 地址反向 DNS 查询
- **IP计算器**：子网计算与地址规划

### 网络调试
- **网络测速**：在线测速
- **HTTP调试**：发送 HTTP 请求并查看完整响应
- **网页调试**：正则、Jsoup、Xpath 解析网页
- **内置浏览器**：轻量浏览器，支持 eruda 调试面板

### 设备调试
- **ONVIF调试**：发现、配置、管理 ONVIF 摄像头
- **SADP调试**：海康威视 SADP 协议设备搜索
- **RTSP预览**：RTSP 视频流播放

### 局域网聊天
- 去中心化局域网即时通讯，无服务器架构
- 支持好友聊天、房间群聊、设备自动发现
- 同一设备多开可通过 IP:端口 格式添加

### 其他工具
- **应用管理**：查看和管理已安装应用
- **图标转换**：SVG 与 Android Vector XML 互转

## 设置页面

应用全局配置与信息：

- **主题设置**：浅色/深色/跟随系统
- **主题颜色**：7 种预设主题色
- **扫描速度**：快速/标准/慢速
- **扫描历史**：历史扫描记录查看
- **运行日志**：实时日志（错误/调试/广播）
- **关于软件**：版本与简介
- **更新日志**：版本更新记录
- **使用帮助**：当前页面
