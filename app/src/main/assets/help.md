# 使用帮助

网络工具箱是一款本地优先的 Android 网络调试工具。以下内容按常见使用场景整理，遇到问题时可以先在这里查找。

## 快速开始

- **首页**：查看当前网络、IP、网关、DNS 和常用工具入口。
- **设备**：扫描同一局域网内的在线设备。
- **无线**：查看当前 WiFi、扫描附近网络、连接 WiFi、管理 WiFi 数据。
- **工具**：Ping、端口扫描、DNS、HTTP 调试、SADP、ONVIF、RTSP、局域网聊天等。
- **设置**：主题、权限、扫描速度、检查更新、使用帮助和关于软件。

## 常见问题

### 怎么导入 WiFi 数据？

请按下面路径操作：

- 打开底部 **工具** 页面
- 找到 **WiFi 数据** 分类
- 点击 **WiFi 导入**
- 点击 **选择文件导入**

Android 11 及以上首次使用会提示授予“所有文件访问权限”。这个权限只用于让应用内文件浏览器读取你选择的本地备份文件；如果不想授权，也可以在提示框中选择系统文件选择器。

文件浏览器顶部提供：

- **根目录**
- **Download**
- 路径和“上一级”按钮

支持导入：

- 网络工具箱自己导出的 JSON / TXT
- 加密的旧版 title/content JSON
- MIUI、部分安卓手机的 `.bak` 备份
- vivo 设置备份
- ZIP 压缩包（包括 ZIP64 / MIUI 备份）
- wpa_supplicant 配置
- 文本化的 `wifiConfig` 数据库

选择文件后会显示导入结果。导入数量按 SSID 和密码记录统计，已有相同 SSID 的数据会合并。

### 导入后去哪里查看 WiFi 密码？

有两种方式：

- **无线** 页面长按某个 WiFi，底部会列出该 WiFi 已保存的全部密码，每个密码可以单独复制。
- 打开 **工具 → WiFi 数据 → WiFi 数据库**，可以看到所有已导入的 WiFi、密码数量标签和记录。

数据库页：

- 点击或长按记录会打开底部密码操作面板
- 支持复制、删除和撤销删除
- 标题栏的“清除空密码”会删除空密码、NONE 以及开放网络的“空密码”占位记录
- 搜索框可以按 SSID 或密码筛选

### WiFi 连接提示缺少 WiFi 连接权限怎么办？

如果提示中包含 **android.permission.CHANGE_NETWORK_STATE** 或 **android.permission.WRITE_SETTINGS**，说明系统在调用 WiFi 连接 API 时没有找到 `CHANGE_NETWORK_STATE` 声明。这个权限是普通权限，不需要用户在设置里手动点“允许”，但必须由 APK 的 AndroidManifest 声明。

**旧版 APK 缺少该声明，安装最新版本即可。** 应用并不需要 `WRITE_SETTINGS`，系统提示的是“二者之一”，当前版本使用 `CHANGE_NETWORK_STATE`。

安装后如果仍然失败，请检查：

- 设置 → 应用 → 网络工具箱 → 权限
- **附近的设备 / 附近 WiFi 设备**：允许
- **位置信息**：允许，并选择**精确位置**
- 系统 **位置信息总开关**：开启
- 部分手机还需要在定位设置中开启 **WiFi 扫描**

连接时 Android 可能弹出系统确认窗口，需要点击允许。部分厂商系统或工作配置会限制应用直接连接 WiFi，此时请使用“系统 WiFi 设置”手动连接。

### 为什么扫描不到全部设备？

设备扫描不是只做 Ping，会组合使用：

- ARP 表 / NDP 表
- IPv4 / IPv6 邻居
- ICMP Ping
- SSDP / mDNS
- NetBIOS
- UDP 广播
- ONVIF / SADP
- HTTP 和常见服务端口

但以下情况仍可能导致设备不可见：

- 路由器开启了 AP 隔离
- 设备防火墙禁止 ICMP 或端口探测
- 设备处于另一个网段
- Android 系统限制读取 ARP / NDP 表
- IPv4 当前只完整扫描本机所在 `/24`，跨网段设备不会被自动扫描

### 为什么设备 MAC 显示“未获取”？

Android 对 ARP / NDP 和 WiFi 信息有权限限制，部分设备或系统版本只能看到 IP，无法读取 MAC。应用会尽量从 ARP、NDP、SADP 和抓取到的设备信息补全，但不能保证所有设备都能显示。

### RTSP 预览无法播放怎么办？

当前使用 Media3 ExoPlayer RTSP：

- 支持标准 RTSP over TCP
- 支持 RTSP over UDP 单播
- 支持 Basic / Digest 认证
- 视频编码取决于设备是否支持 H.264 / H.265

以下情况可能无法播放：

- 厂商私有的 RTSP 封装
- RTSP over HTTP
- 加密流
- UDP 组播
- 设备使用了手机不支持的编码

可以尝试：

- 在预览页切换 TCP / UDP
- 确认 RTSP 地址包含正确的用户名和密码
- 使用 VLC 或其他播放器验证地址是否可播放
- 对不支持的流使用系统或电脑端播放器

### ONVIF / SADP 搜索不到摄像头？

- 确认手机和摄像头在同一局域网
- ONVIF 需要摄像头开启 ONVIF 并设置账号密码
- SADP 主要用于海康设备，设备需要允许 SADP 发现
- 检查路由器是否开启 AP 隔离
- 有线网络和 WiFi 可能属于不同网段

### 局域网聊天搜不到好友？

- 两台设备必须连接同一局域网
- 设备防火墙或路由器 AP 隔离可能阻断发现
- 首次使用需要设置昵称
- 需要通知权限才能在后台收到消息提醒
- 好友发现依赖 UDP 广播 / 组播，部分企业网络会限制

### 怎么导出 WiFi 数据？

打开：

- 工具 → WiFi 数据 → WiFi 导出

可以选择：

- JSON 加密
- JSON 明文
- TXT 文本

列表右侧会显示“2 个密码”等数量标签。标题栏的“全选 / 取消全选”可以快速选择记录。导出的文件会保存到你选择的目录。

### 怎么检查更新？

设置 → 关于与帮助 → 检查更新。

应用会请求 GitHub Releases 的最新版本。当前仓库需要发布 Release 后才能返回版本；如果没有 Release，会提示“仓库还没有发布 Release”。

### 数据会被上传吗？

不会上传 WiFi 密码、聊天记录、设备信息或导入文件。业务数据保存在应用私有目录中，只有你主动发起网络请求时，应用才会访问对应网络。

## 权限说明

- **附近的设备 / 附近 WiFi**：扫描和连接附近 WiFi（Android 13+）
- **位置信息**：WiFi 扫描和部分连接 API 需要精确位置
- **WiFi 状态**：读取 WiFi 信息
- **网络状态**：读取网络和发起连接请求
- **CHANGE_NETWORK_STATE**：普通权限，安装时自动授予，用于发起 WiFi 连接
- **存储 / 所有文件访问**：应用内文件浏览器读取你选择的备份文件
- **相机**：扫一扫和摄像头相关功能
- **通知**：局域网聊天消息提醒

## 还是无法解决？

请通过 GitHub Issues 反馈：

- 应用版本
- Android 版本和设备型号
- 具体操作步骤
- 错误提示截图

请勿上传真实 WiFi 密码、聊天数据库或私人备份文件。
