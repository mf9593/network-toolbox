# 隐私政策

**更新日期：2026年7月9日**

本应用尊重并保护用户隐私。本隐私政策说明我们如何收集、使用和保护您的信息。

## 信息收集

本应用**不收集**任何用户个人信息。

- 不收集姓名、电话、邮箱等个人身份信息
- 不跟踪使用行为或位置信息
- 不使用任何第三方分析或广告 SDK
- 所有网络诊断数据仅在本地处理，不会上传

## 权限使用

应用请求的权限仅用于提供相应功能：

- **网络访问**：用于网络诊断、HTTP调试、网页测速等
- **WiFi 状态**：用于扫描和显示 WiFi 信息
- **定位权限**：Android 系统扫描 WiFi 需要定位权限
- **相机权限**：用于虚拟摄像头功能
- **存储权限**：用于导入/导出数据文件、保存日志

## 数据存储

所有数据均存储在用户设备本地，不会上传到任何服务器：

- WiFi 密码使用 AES 加密保存在本地
- 应用设置保存在 SharedPreferences
- 运行日志保存在本地，用于故障排查

## 第三方服务

本应用可能通过 WebView 加载第三方测速网站，这些网站有自己的隐私政策，请参阅各网站说明。

## 变更通知

如本隐私政策有重大变更，我们会通过应用更新通知您。

## 联系我们

如有疑问，请通过应用内反馈功能联系我们。
