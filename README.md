# 网络工具箱

一款面向 Android 平台的本地网络调试与诊断工具，采用 Java + Material Design 3 开发，无需 Root。

> 当前版本：2.1.1 (211)
>
> 下载：<https://github.com/mf9593/network-toolbox/releases/latest>

## 核心功能

- **网络概览**：实时展示 WiFi / 有线网络的 IP、网关、DNS、频率、速率、延迟与信号强度曲线；硬件信息区在未充电时显示实时功率，充电时显示充电功率
- **局域网设备扫描**：WiFi 与以太网双通道，支持主动 / 安静 / 被动三种扫描模式；通过 ARP、mDNS、NetBIOS、SSDP、ONVIF、SADP、UDP 广播等多协议交叉识别设备，支持跨网段扫描、IPv4 / IPv6 与协议组合筛选
- **路由器识别**：自动识别网关与常见路由器品牌（TP-Link、华为、小米、荣耀、中兴、腾达、华硕、H3C、锐捷等 20 个品牌），设备详情可查看各协议识别到的全部名称，并支持自定义标题来源优先级
- **WiFi 管理**：扫描周边网络、连接 WiFi、查看系统已保存网络与密码，支持 WiFi 数据加密导入 / 导出与本地密码库查询
- **摄像头调试**：ONVIF / SADP 设备发现与配置、RTSP 预览、按品牌生成 RTSP 地址
- **运行报文**：Ping、端口、NetBIOS、路由器等探测过程可随时在「运行日志」中查看，方便核对协议交互
- **本地优先**：所有业务数据仅在设备本地处理，不上传任何服务器

## 工具清单

### 网络诊断

| 工具 | 说明 |
| --- | --- |
| Ping | 测试主机连通性、延迟与丢包 |
| 端口扫描 | 检测目标主机的开放端口 |
| IP 扫描 | 发现同网段主机，点击结果探测常见后台 / 摄像头端口 |
| 路由追踪 | 逐跳查看数据包经过的网络节点 |
| 网络测速 | 网页测速与网络延迟测试 |

### 域名与 DNS

| 工具 | 说明 |
| --- | --- |
| DNS 优选 | 对比公共 DNS 的响应延迟 |
| DNS 反查 | 根据 IP 查询关联域名 |
| 域名查询 | 查询域名 Whois 与注册信息 |
| IP 计算器 | 子网掩码与网段计算 |

### WiFi 与局域网

| 工具 | 说明 |
| --- | --- |
| 导入 WiFi 数据 | 从文件或文本导入网络数据 |
| 导出 WiFi 数据 | 导出已保存的网络数据 |
| 数据库查询 | 搜索本地 WiFi 密码库 |
| 已保存网络 | 查看系统已保存的网络 |
| 局域网聊天 | 同一局域网内收发消息、传输 WiFi 数据 |

### 摄像头与流媒体

| 工具 | 说明 |
| --- | --- |
| ONVIF 调试 | 发现并调试 ONVIF 摄像头 |
| SADP 调试 | 海康设备发现与配置 |
| RTSP 预览 | 播放 RTSP 视频流 |
| RTSP 地址生成器 | 按品牌模板生成摄像头 RTSP 地址 |
| 电视直播 | 加载 M3U / M3U8 / TXT / JSON 直播源 |
| 投屏 | 投屏图片、视频与直播链接到电视 |

### Web 与 HTTP

| 工具 | 说明 |
| --- | --- |
| HTTP 调试 | 发送 GET / POST 接口请求 |
| 网页调试 | 抓取并解析网页内容 |
| 内置浏览器 | 轻量网页浏览器 |

### 系统与实验室

| 工具 | 说明 |
| --- | --- |
| 应用管理 | 查看与导出已安装应用 |
| MAC 地址查询 | 查询 MAC 厂商与地址信息 |
| 图标转换 | SVG / PNG 图标格式转换 |
| 电池优化 | 跳转系统电池优化设置 |

工具页支持搜索、分组、最近使用与「我的常用」（最多 10 个，长按可排序）。

## 技术特性

- 单模块纯 Java 实现，Material Design 3 设计
- 深色模式与自定义主题配色，全局跟随系统与主题色
- 原生库 16KB 页对齐，兼容 Android 15+ 16KB 页设备
- 最低支持 Android 5.0（API 21），目标 Android 14（API 34）

## 构建

环境：

- JDK 21
- Android SDK 34
- Gradle 8.13 / Android Gradle Plugin 8.7.3

```bash
./gradlew assembleDebug
```

生成：

```text
app/build/outputs/apk/debug/app-debug.apk
```
