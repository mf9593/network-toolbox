## 图标转换：pathData 解析器错误导致预览图标缺块（2.1.3）

- 背景/问题：
  - 用户反馈「工具 → 图标转换」转换出来的图标显示不对。给的样例是 Material 的
    「文档 + 机器人脸」图标（`M6 22q-.825 0-1.412-.587T4 20V4…T18 22z m1-3h10…`），
    转换出的 XML 里 pathData 是原样复制的，预览里却只剩一个文档外框，里面的机器人脸不见了。
  - 根因：预览（`renderXmlDrawable`）走的是项目内手写的 `SvgRenderer.svgPathToAndroidPath`，
    正则拆命令 + 自己维护当前点。`z` 闭合时**没有把当前点复位到子路径起点**，
    紧跟其后的相对 `m` 就整体偏移。用同一份 pathData 跑数值对比：
    正确应为 `m1-3` → `(7,19)`，旧实现算出 `(19,19)`，内层图形整体右移 12px、
    最远到 x=29，超出 24×24 画布被裁掉，正好把脸裁没了。
- 改动文件：
  - `app/src/main/java/com/networktool/app/util/SvgRenderer.java`：
    删除约 190 行手写 pathData 解析器（含 `svgArc`），改为委托
    `androidx.core.graphics.PathParser.createPathFromPathData()`。
  - `app/src/main/java/com/networktool/app/activity/tool/IconConverterActivity.java`：
    新增 `previewInkColor()` / `forPreview()`，深色主题下纯黑图标改用主题文字色做预览，
    修掉「深色下预览一片黑」；`currentColor` 也走同一逻辑。
    仅影响预览，导出/复制仍是原始颜色。
  - `app/build.gradle`：`versionCode 213` / `versionName "2.1.3"`。
- 关键实现：
  - `androidx.core.graphics.PathParser` 就是 `VectorDrawableCompat` 解析 pathData 用的同一份实现，
    对齐、弧线、指数、隐式重复参数、`z` 闭合语义全部与真机渲染一致，
    预览不会再和实际效果对不上（符合「标准格式解析不要手写正则」的约定）。
- 验证：
  - 数值对比：同一份 pathData，修正后各段端点与 SVG 规范一致（`z` 后复位到 `(6,22)`）。
  - 实机（M511CD，SDK 37）：把该 XML 临时设为示例，预览显示完整的「文档 + 机器人脸」，
    机器人脸居中在文档内部，不再被裁掉。
- 产物：`app/build/outputs/apk/debug/app-debug.apk`（12,855,788 字节），
  签名 `c20a8284…a9e3f7`，`zipalign -c -P 16 4` 通过，`versionCode 213 / 2.1.3`。
- 待办：
  - 深色主题下 `currentColor` / 纯黑图标的预览换色**只做了代码修改，未实机截图确认**（待验证）。

### 关键实现
- **弹窗底边露出导航栏的根因**：`BottomSheetBehavior` 在 `fitToContents=false` 后是
  「顶部对齐 + `expandedOffset`」定位。之前把高度设成屏幕的 92%、`expandedOffset=0`，
  弹窗底边就停在 92% 处，剩下 8% 露出底下的 Activity（底部导航栏）。
  现在高度取 `可用高度 − (状态栏高度 + topGapDp)`，`expandedOffset` 同步设为同一值，
  展开后底边正好压到屏幕最底部。
- **滑到底再上滑不关闭**：内容放在 `NestedScrollView`（`fillViewport=true`、`layout_height=0dp` + weight 1），
  标题和保存按钮在滚动区外。滚到底后再上滑只是内容区 overscroll，不会拖动整个弹窗。
- **协议筛选 14 项**用 `capHeight(dialog, 0.8f)`：高度跟内容走，超过 80% 屏高才内部滚动，
  避免只有 2 项的排序弹窗也被撑到全屏。
- 排序 / 筛选 / IP 版本三个弹窗共用 `ScanOptionAdapter` + `item_scan_option.xml`，
  选中态＝主题色 2dp 描边 + 浅主题底 + 右侧勾，颜色全部来自 `ThemeManager`。

### 补充：已保存网络改用 Shizuku 授权读取（含明文密码）

背景：
- 「已保存网络」页此前走 `WifiManager.getConfiguredNetworks()`，Android 10+ 上密码返回占位符，

- 已实测确认：shell 读 `/data/misc/apexdata/com.android.wifi/WifiConfigStore.xml` 是 Permission denied，

关键坑：
1. **`Shizuku.newProcess` 在 13.1.5 是私有的**，不能用来跑命令；官方支持的路径是 UserService
   （`Shizuku.bindUserService(UserServiceArgs, ServiceConnection)`），AIDL 接口的 Stub 类由 Shizuku
   在自己的进程里反射实例化，不需要在 Manifest 注册 Service。
2. **AIDL 的 `out` 不能用于原始类型**，`out int` 报 "int can only be an in parameter"，改用 `out int[]`；

3. **本机 build-tools 34.0.0 的 `aidl` 是 x86-64**，在 aarch64 上无法执行，AGP 用 shell 兜底执行时

   （其 aidl / aapt2 / zipalign 都是 aarch64）。
4. **`android.util.SuppressLint` 不存在**，注解在 `android.annotation.SuppressLint`。
5. **Shizuku 的授权常量是系统的**，`checkSelfPermission()` 返回 `PackageManager.PERMISSION_GRANTED`，
   不是 `Shizuku.PERMISSION_GRANTED`。
