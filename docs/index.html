QUESTIONS

常见问题

需要 Root 吗？

不需要。设备扫描和 WiFi 工具基于 Android 公开 API 实现，部分系统限制会影响 MAC 或扫描结果，应用会尽量使用系统允许的方式补全。

会上传我的 WiFi 密码吗？

不会。WiFi 数据以加密形式保存在应用私有目录，导入和导出只由你主动操作。应用没有统计 SDK 或账户系统。

为什么部分设备扫描不到？

Android 的网络权限、路由器的 AP 隔离、设备防火墙和跨网段都会影响发现结果。应用会组合 ARP、NDP、多播和端口探测，但不能绕过所有网络隔离。

如何反馈问题？

请通过 GitHub Issues 提交，附上 Android 版本、设备型号、复现步骤和相关截图。请勿上传真实 WiFi 密码或私人备份文件。
